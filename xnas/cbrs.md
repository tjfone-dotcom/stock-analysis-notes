# Cerebras Systems (CBRS)

## 현재 결론

- 기준시각: 2026-10-22 00:04:34 KST = 10/21 11:04:34 EDT 장중.
- 핵심 행동: 신규 매수 보류, 기존 고비중 비중축소. 작은 장기 위험자금은 실적 확인하며 유지 가능.
- 신규 자금: 현재가 추격 회피. 기본 가설 유지 시 $70~80에서 소규모 재검토.
- 기존 보유자: 고객·가동·현금 가설이 유효하고 추가 큰 손실을 감내할 수 있는 작은 비중에 한해 유지 여지. 코어·고비중은 축소 쪽.
- 투자 기간: 실적 검증 1~2분기, 사업가치 2027년 말.
- 확신도: 판단 중간, 가치 추정 중하.
- 기준가격: $116.42, 전일 $118.24 대비 -1.54%.
- 기준 시나리오: 2027년 말 $98.41, 연14%·435일 할인 현재가치 $84.18. 자체 가정이며 확정 적정가가 아님.
- 한 문장 논지: 고속 추론의 실제 고객 도입은 긍정적이지만 희석·증설비용을 반영하면 매출 세 배 성장만으로 현재 가격의 안전마진이 확보되지 않는다.

## 무엇이 시장 기대와 다른가

- 시장이 가격에 반영한 기대: OpenAI·AWS를 통한 고속 추론 확산과 2027년 세 배 이상 성장 계획.
- 내 판단의 엣지: 총매출보다 주당 현금창출. Core 매출로 평가할 때 고객 워런트의 경제적 희석을 분모에 반영한다.
- 기대를 검증할 촉매: 11/12 Q3 실적, 가동·유료 사용·현금총이익·주식 수 업데이트.
- 현재 가격을 자체 기준 모형에서 정당화하려면 2027 Core 매출 약 $4.32bn이 필요하다. 9배·순현금 $4bn·315m주·14% 할인 유지 가정.

## 사업과 실적 논지

### 긍정 논지

- 대형 웨이퍼 시스템·클라우드 서비스. 저지연 decode가 경쟁력의 핵심이며 GPU 전면 대체와 구분한다.
- 8/18 CS-4 발표. AMD·AWS 장비와 역할을 나누는 이종 추론도 가능하다. 속도·전력효율 수치는 회사의 특정 조건 벤치마크다.
- OpenAI가 8/13 제한 Ultrafast 프리뷰에서 Cerebras 사용을 직접 확인했다. 모든 최신 모델 독점 공급을 뜻하지 않는다.
- 9/1 핀란드 7년 서비스 주문과 50→80→165MW 확장은 고객·지역 다변화 가능성. €1~1.7bn은 지역 투자효과 추정이지 CBRS 확정 매출·단독 CAPEX가 아니다.

### 부정 논지

- Core 매출 = GAAP180.110 − 비용 재청구14.503 + 워런트 상각44.262 =209.869 (USD m).
- 고객 워런트는 현금비용이 아니어도 주주 몫을 줄인다. Core 조정과 경제적 희석을 동시에 봐야 한다.
- 2025 순이익237.827m에는 선도계약 부채 소멸 이익363.336m이 포함. 단순 차감은 -125.509m이며 정규화 EPS로 부르지 않는다.
- Q2 SBC377.008m에는 IPO catch-up이 크다. 전액 연율화나 전액 영구제외 모두 부적절하다.
- OpenAI 기본750MW와 추가1.25GW 옵션을 분리. RPO는 매출·현금·이익이 아니다.
- OpenAI loan은 6%·서비스 credit 상환과 계약조건이 있다. 미인출850m 한도를 보유현금에 더하지 않는다.
- 미개시 리스1.5bn 및 Q3추가0.7534bn은 미래부담. 운영비·리스·기업가치에서 같은 비용을 중복 차감하지 않는다.

## 밸류에이션

- 방법: (2027 Core 매출×EV/매출+미래 순현금)/미래 경제적 희석주식 수.
- 미래 순현금은 CAPEX·운영손실·조달·행사대금의 순효과를 가정한 값. 상세 자금수지 모델과 회사 전망이 아니다.
- 6/30 고객 워런트26.108m에는 잔여 OpenAI23.411518m와 AWS2.696678m 포함. 7월 행사10.033508m를 또 빼지 않는다.
- 237.564+76.011=313.575m은 날짜가 다른 재고 합계이며 정확한 현재 완전희석주식 수가 아니다. 옵션 자기주식법·성과조건·추가보상에 따라 변한다.
- 비관330m은 추가자금조달·보상, 기준315m은 공시 잠재희석 대용, 낙관325m은 성과조건·추가보상을 가정. 추가 조달의 현금은 순현금 가정에 포함.
- 현재가치는 미래 가격을 1.14^(435/365)로 할인. 기준98.4127/1.1690097=84.1847.
- 배수±2배면 기준 현재가치 약±16.3달러, 미래순현금±1bn이면 약±2.7달러.

- 매수 보류 반증: 매출3.5~4bn 이상 전망이 구체화되고 희석·현금소진이 예상보다 작으며 마진도 개선.
