# 종목별 투자 노트

종목 파일은 주 상장 시장의 MIC와 티커를 사용해 `stocks/<mic>/<ticker>.md`에 만든다. 예시는 삼성전자 `stocks/xkrx/005930.md`, Microsoft `stocks/xnas/msft.md`다.
